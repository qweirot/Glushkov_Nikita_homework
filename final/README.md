# Анализ Нобелевских лауреатов

Финальный проект по анализу данных о Нобелевских лауреатах.

Данные получаются через **Nobel Prize API** и обрабатываются с помощью собственных функций.


### Описание файлов

| Файл | Назначение |
|---|---|
| `laureates_countries_task.ipynb` | Основной ноутбук с анализом и графиками |
| `laureates_configs.py` | Конфигурации обработки лауреатов |
| `prizes_configs.py` | Конфигурация обработки премий |
| `json_dict_processing.py` | Обработка вложенных JSON-данных |
| `dataset_helpers.py` | Фильтрация, группировка и агрегация |
| `aggregations.py` | Вычисление среднего и получение топ-N |
| `atribute_manager.py` | Добавление вычисляемых атрибутов |
| `laureates.json` | Локальная копия данных |
| `requirements.txt` | Зависимости проекта |


## Установка и запуск

**1. Клонируйте репозиторий:**

```bash
git clone <URL_репозитория>
```

**2. Перейдите в папку проекта:**

```bash
cd final
```

**3. Установите зависимости:**

```bash
pip install -r requirements.txt
```

**4. Запустите Jupyter Notebook:**

```bash
jupyter notebook
```

**5. Откройте `laureates_countries_task.ipynb` и выполните все ячейки.**

При запуске данные загружаются из Nobel Prize API. Если запрос не удаётся, используется локальный файл `laureates.json`.

## Проведённый анализ

### 1. Первичный анализ данных (EDA)

- Подсчёт количества лауреатов и организаций.
- Проверка пропущенных значений.
- Анализ идентификаторов и проверка дубликатов.
- Определение временного диапазона данных.

### 2. Топ-статистика по странам

- Определение пяти стран с наибольшим количеством лауреатов.
- Сравнение стран по отдельным категориям премий.
- Визуализация полученных результатов.

### 3. Многократные лауреаты

- Поиск лауреатов, получивших несколько Нобелевских премий.
- Сравнение категорий первой и второй наград.
- Расчёт среднего промежутка между награждениями.

### 4. Отказы от премий

- Поиск случаев отказа от Нобелевской премии.
- Анализ отказов по категориям.
- Проверка отказов среди организаций.




В ходе проекта были реализованы собственные модули для обработки JSON, фильтрации, группировки и анализа данных.

Результаты представлены в Jupyter Notebook в виде статистических показателей, графиков и выводов.
