# Домашнее задание №2

## Описание проекта

Программа на Python для обработки данных о сотрудниках компании из CSV-файла `Corp_Summary.csv`.

Программа позволяет получить информацию о структуре компании, рассчитать статистику по зарплатам сотрудников и сохранить результаты в отдельный CSV-файл.

## Требования

Для работы программы необходимо:

- Python 3
- Файл `Corp_Summary.csv` с данными сотрудников (уже включён в проект)

Дополнительные библиотеки не требуются. Используется стандартный модуль Python `csv`.

## Формат входных данных

Программа использует файл `Corp_Summary.csv`, содержащий следующие столбцы:

| Столбец | Описание |
|---|---|
| ФИО | Фамилия, имя и отчество сотрудника |
| Департамент | Название департамента |
| Отдел | Команда или отдел сотрудника |
| Должность | Должность сотрудника |
| Оценка | Оценка сотрудника |
| Оклад | Зарплата сотрудника |

Разделитель столбцов - точка с запятой (`;`).

**1. Склонировать репозиторий**

```bash
git clone <ссылка-на-репозиторий>
```

**2. Перейти в папку проекта**

**3. Перейти в папку второй домашней работы**


```bash

```

**5. Выбрать нужный вариант отчёта**

После запуска программа предложит ввести номер отчёта.

Введите `1`, `2` или `3` и нажмите Enter.

## Варианты отчётов

### 1. Иерархия департаментов

Выводит список всех департаментов компании и команд, входящих в каждый департамент.

Для запуска введите `1`.


### 2. Статистика по департаментам

Выводит сводную информацию о зарплатах сотрудников для каждого департамента.

Для запуска введите `2`.

Для каждого департамента рассчитываются:

- Название департамента
- Количество сотрудников
- Минимальный оклад
- Максимальный оклад
- Средний оклад


### 3. Экспорт статистики в CSV

Формирует ту же статистику, что и второй вариант, но сохраняет её в отдельный CSV-файл.

Для запуска введите `3`.

В результате создаётся файл `output.csv` со следующими столбцами:

- Департамент
- Количество сотрудников
- Минимальный оклад
- Максимальный оклад
- Средний оклад

Выходной файл создаётся автоматически в рабочей директории программы. Если файл уже существует, его содержимое перезаписывается.
